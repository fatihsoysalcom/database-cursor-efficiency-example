# Database Cursor Efficiency Example

This Python script demonstrates the efficiency of database cursors when processing large datasets. It compares fetching all records into memory at once versus fetching them one by one using a cursor, highlighting memory usage benefits.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
